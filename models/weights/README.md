# Model Weights Directory

Place model weight files here:
- `yolov8n.pt` / `yolov8s.pt`: Object detection weights
- `midas_v21_small.pt`: Monocular depth estimation weights
- `weather_classifier_resnet18.pth`: Weather classification weights
- `glare_risk_gbm.json` / `glare_risk_gbm.pkl`: XGBoost / LightGBM glare risk weights
